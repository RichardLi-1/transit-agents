# Site photos

Photos of the Ontario Line corridor, from Wikimedia Commons. The media agent
passes them to Nano Banana 2 for a site's terrain, roads and existing buildings.
Each is the file Commons serves at 1280 px or less. Only CC0 and CC BY photos are
here, never share-alike. What each shows, and where, is in `manifest.json`.
